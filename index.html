Instrucciones de Uso

  1. Selecciona el Número de Punto entre 1 y 30.
  2. Completa los campos: placa del tractocamión, remolque, autotanque, transportista, chofer, producto y capacidad.
  3. Haz clic en Agregar registro para guardar el dato localmente.
  4. Repite para cada nuevo registro que desees agregar durante el día.
  5. Al terminar, usa el botón Descargar Excel del Día para bajar el archivo con todos los registros guardados.
  6. El sistema limpia automáticamente los registros cada día.
  7. Para cualquier problema o duda, refresca la página y revisa las instrucciones nuevamente.
